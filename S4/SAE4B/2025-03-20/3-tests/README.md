# Introduction
Cet utilitaire permet de tester plusieurs aspects (connectivité, DNS, DHCP...) de l'infrastructure mise en place durant la SAE4.B. Il est à exécuter sur l'hyperviseur et utilise Python.  
Afin de réaliser des tests distants, les programmes peuvent créer une connexion SSH vers un hôte distant. Le fichier `hosts.csv`, dont un exemple est donné, décrit ces hôtes. Ce fichier est formatté comme un fichier CSV `(ip, user, displayName)` et décrit les hôtes sur lesquels peuvent être conduits les tests. Il contient l'IP de chaque machine, un utilisateur que l'hyperviseur peut utiliser pour les tests ainsi que le nom d'affichage de cet hôte.   
L'utilitaire est lancable avec le fichier `main.py` pour lancer toute la suite de tests, ou bien avec `PROGRAMME.py hosts.csv tests.csv` pour lancer un test en particulier.

## Connectivité
Ce programme s'utilise avec la commande `python3 connectivite/main.py hosts.csv tests.csv`. Il utilise les fichiers `hosts.csv` et `tests.csv` afin de réaliser des tests simples de connectivité avec l'utilitaire `ping`. Le fichier `tests` est formatté comme un fichier CSV `(sip, dip, expected)` et décrit les tests à conduire. Il contient l'IP source et destination de chaque `ping` ainsi qu'un oracle sur la réussite de ce test ('t' pour un réussite, 'f' pour un echec). L'utilitaire se connecte en SSH à l'hôte d'IP `sip` avec l'utilisateur indiqué dans `hosts`, puis ping `dip`. En cas de résultat différent de l'oracle, un message d'erreur est affiché dans la sortie standard. Enfin, le nombre total de tests ainsi que le nombre d'échecs est affiché dans la sortie standard.

## DNS
Ce programme s'utilise avec la commande `python3 dns/main.py hosts.csv tests.csv`. Il utilise les fichiers `hosts.csv` et `tests.csv` afin de réaliser des tests de résolution de nom de domaine avec l'utilitaire `dig`. Le fichier `tests.csv` est formatté comme un fichier CSV `(dns, dn, expected)` et décrit les tests à conduire. Il contient l'ensemble des serveurs DNS à tester, avec le nom de domaine associé ainsi qu'un oracle sur la réussite de ce test ('t' pour un réussite, 'f' pour un echec). En cas de résultat différent de l'oracle, un message d'erreur est affiché dans la sortie standard. Enfin, le nombre total de tests ainsi que le nombre d'échecs est affiché dans la sortie standard.
